## Reading the matrix

**The gap is asymmetric.** On product substance (voice depth, inbox, CRM memory, honesty,
billing) Denku is at or above the benchmark once flags flip: 8 rows score BETTER with effort ≤4.
On business machinery (funnel, templates, packs, audit, marketplaces, partners) Denku is at ~0
and every PARITY row is packaging/GTM work, not platform work.

**Priority stack that falls out (feeds doc 20):**
1. **P0 — Turn it on** (deploy, flip flags, live demo line, dogfood) — no new product code.
2. **P1 — Wrap it in a business** (new site + pricing ladder + templates + instant AI audit +
   calendar booking + SMS/missed-call + minute packs + outcome digest + trust page).
3. **P2 — Widen the moat** (web-chat widget + widget studio, SEO/AEO engine, marketplace
   listings, pipeline+scoring, IG when Meta unblocks).
4. **P3+ — Scale distribution** (partner program, vertical wedge deepening, Studio/e-com
   adjacencies only if evidence demands).
